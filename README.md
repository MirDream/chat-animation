# chat-animation · 用 Git 管理「微信聊天动画」的版本演进

一个用 **纯 HTML/CSS/JS** 写的微信风格聊天动画，作为 Git 版本管理的练习载体：它不是重点，重点是它被怎么管理。

## 这个仓库想说明什么

**满意就 commit，不满意就 checkout / reset 回退再创。**

动画改坏了能回，做对了能留；本地的存档能推到远程共享，多人的工作能用分支并行、再用合并请求合到一起。

## 版本轨迹

```
* v3 优化细节与主题      ← 时间药丸、气泡尾巴、柔和阴影、绿色输入提示
* v2 消息自动播放动画    ← 逐条弹出、正在输入、自动滚底、整体循环
* v1 静态聊天界面        ← 两条静态消息的静态界面
```

每一版都能用 `git checkout <sha>` 或 `git reset --hard <sha>` 精确回到当时的样子。

## 跑起来

浏览器直接打开 `index.html` 即可，无依赖、无构建。

也可以起个本地服务：

```bash
python3 -m http.server 8080
# http://127.0.0.1:8080
```

## 三个版本各做了什么

### v1 · 静态聊天界面

375×720 手机尺寸，顶部「码道小助手」标题栏，聊天区两条静态消息：对方「在吗？」在左（白气泡），我「在的，怎么啦？」在右（绿气泡 `#95ec69`，圆角 8px）。

### v2 · 消息自动播放动画

- 7 句对话按脚本逐条弹出，整体循环播放
- 对方发消息前先出现「正在输入」的三点动效
- 新消息出现后自动滚动到底部
- 气泡带轻微的上浮淡入

### v3 · 优化细节与主题

- 时间分割线改为灰底圆角小药丸
- 气泡增加朝向头像的小尾巴（用 CSS `::before` 三角实现）
- 气泡加柔和双层阴影，绿色微调到更舒服的 `#95ec69`
- 「对方正在输入」文字变绿，省略号逐点闪烁

## 用到的 Git 命令

```bash
git init                       # 建立仓库
git add index.html             # 暂存
git commit -m "v1 静态聊天界面"  # 拍一张快照
git log --oneline --graph      # 看提交时间线
git checkout -- index.html     # 丢弃工作区未提交的改动
git reset --hard HEAD          # 强制回到最近一次提交
git checkout <sha>             # 穿越到历史版本（detached HEAD）
git checkout main              # 再切回来
```

## 协作部分

远程仓托管与协作通过分支 + 合并请求完成：

- `main` 承载 v1 → v2 → v3 的完整演进
- `feature/bubble-theme` 在 v3 基础上继续打磨气泡主题，通过合并请求评审后合入
